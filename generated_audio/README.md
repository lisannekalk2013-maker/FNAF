# Gegenereerde voorbeeldgeluiden

Deze PCM-WAVs zijn door de bestaande app gegenereerd en worden meegeleverd zodat het project ook de geluiden bevat. De app blijft zijn eigen exemplaren in de persoonlijke instellingenmap genereren; de afspeellogica is niet aangepast. Om deze bestanden als eigen assets te gebruiken, zie `assets/README.md`.
