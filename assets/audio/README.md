# Eigen audio

Plaats PCM-WAV bestanden hier om de meegeleverde synthetische varianten te vervangen:

freddy_scare.wav, bonnie_scare.wav, chica_scare.wav, foxy_scare.wav, golden_freddy_scare.wav, springtrap_scare.wav.

Overige effecten: freddy.wav (lach), foxy_sprint.wav, camera_static.wav, golden_glitch.wav, theft.wav, ambient.wav, chica.wav.

Alleen media toevoegen waarvoor je rechten/toestemming hebt. Er worden geen originele gamebestanden meegeleverd. Bij een eigen jumpscarevideo wordt het ingebouwde videogeluid gebruikt, behalve als je hier ook een bijbehorende *_scare.wav hebt geplaatst. Videogeluid heeft dezelfde volumelimiet en stille modus. Afspelen wordt na maximaal circa tien seconden gestopt. Geen crash bij ontbrekende bestanden.
